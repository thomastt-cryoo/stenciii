# Stencil Studio - product information for seller review

Draft copy only. No Etsy listing, public release or hosting was created. Read the
M8 readiness decision before offering a platform for sale.

**Suggested factual title:** Stencil Studio - Offline Browser Stencil Maker for
Windows and Mac - STL and Manufacturing ZIP Export

Stencil Studio turns image or text artwork into stencil files you can inspect,
customize and export. It runs locally in your installed browser after you
double-click a small graphical launcher. There is no account, subscription,
cloud processing or recurring licence-server check.

Included capabilities are artwork cleanup, stencil styles, size/thickness/bridge
adjustment, geometry controls, 3D inspection, multi-colour plates, printable
sections, mounting parts, connectors/hardware and local batch variations.
Export STL or a manufacturing ZIP as the selected workflow permits. Save portable
project JSON files containing artwork and settings to continue later.

The five-file download set contains:

- StencilStudio-Windows-x64.zip
- StencilStudio-macOS-Apple-Silicon.zip
- StencilStudio-macOS-Intel.zip
- StencilStudio-Quick-Start.pdf
- Read Me and Checksums.txt

Customers use the ZIP for their own platform. This is digital software; no
physical stencil, printed part, slicer, printer, material or browser installer is
included. No native desktop editor, Electron, Tauri or cloud service is included.

Chrome is recommended. Edge is supported on the tested Windows configuration.
Measured full runtime systems are Windows 11 Home 10.0.26300, Apple Silicon
macOS 26.6.2 and Intel macOS 15.7.9. Exact browser builds appear in the package's
dated Platform Test Record. The current Intel package includes the verified
Safari software 3D repair. Large meshes can be slower in software mode.
Windows Firefox 3D remains unqualified in its tested graphics environment.
Windows 10, older macOS versions and physical Macs beyond CI remain unverified.
Do not market the macOS 13.3 build target as a verified minimum supported OS.

Windows executables are unsigned. Mac launchers are ad hoc signed without Apple
Developer ID signing or notarization. App-specific operating-system approval may
be needed. Managed security policies or Windows Smart App Control can prevent
launch. Do not promise warning-free installation or ask customers to disable
system-wide security. The M8 report distinguishes observed warnings from a
successfully completed approval walkthrough.

The initial download, browser setup and OS security checks may need internet.
Normal artwork processing, project files and exports run locally afterward.
Browser/OS background network services are outside this application's control.

Use Save Project and keep backups outside the application folder. Automatic
drafts belong to one browser/profile/local address, with one draft slot shared
by its tabs. Keep batch jobs open until the collection is downloaded.

Physical printing requires a separate slicer, printer and suitable material.
Geometry validation is not a guarantee of print success, load strength, thread
fit or fastening safety. Check thin features and calibrate printer/material
clearances before producing a complete assembly. Use artwork you have rights to
reproduce. Bundled third-party components/fonts retain their supplied licences;
the application source uses the repository's Unlicense. No exclusive rights to
third-party material are promised.

Seller pricing, support, refund and business terms are intentionally unspecified.
The seller must supply their actual terms. Do not publish this sheet as a claim
that the remaining M8 first-download checks have passed.
