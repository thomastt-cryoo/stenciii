# M7 offline browser review downloads

These five files are the reviewed browser edition for Windows x64, Apple Silicon and Intel Mac. Each ZIP opens the complete local editor in an installed browser. No commercial listing, release tag or hosted editor is activated.

Chrome is recommended on Windows and Mac; Edge is additionally qualified on Windows. Safari passed on Apple Silicon. Intel Safari 3D did not pass; Windows Firefox had a graphics limitation on the test runner. Windows 10 and first-download OS security approval UI were not exercised.

Open [customer downloads](customer) and the [qualification report](https://github.com/thomastt-cryoo/stenciii/blob/main/docs/M7_REPORT.md). Exact sizes and SHA-256 hashes are in delivery-manifest.json and the included checksum text. Checksums detect damage, not publisher identity.
