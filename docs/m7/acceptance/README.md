# Packaged acceptance projects

These portable projects retain the approved M6 artwork and engine recipes. They are test inputs, not assets shipped inside the customer application ZIPs. Corpus provenance is retained in [the original sources record](../../../web/e2e/corpus/SOURCES.md).

The collection covers Standard processing, explicit Smooth Vector processing (including its smooth operation and saved style banks), Crisp Raster, detailed and transparent artwork, a photograph, text, tone patterns, registered colour branches, a 400 mm tiled assembly, mounting, threaded hardware, complete manufacturing archives and a legacy browser graph. The separate package runner also executes a local numeric sweep with actual PNG/SVG preparation attachments and a deliberately forced single-thread fallback.

The Smooth Vector reference is generated by the accepted M6 native executable, whose SHA-256 is checked before use. Its provenance and stored-file hash are retained beside the reference. Export checks validate exact stored coordinates, closure, orientation, normals, ZIP integrity, portable saves and surface equivalence using the M6 integer-lattice method. A missing required reference fails the check.

Package acceptance is separate from the full shared regression suite and M6's 217-control audit. These projects do not imply that every control was manually clicked on each operating system.
