STENCIL STUDIO — OFFLINE BROWSER EDITION FOR MAC

This application bundle is a launcher for the complete local browser editor;
the editor runs in Safari, Chrome or Firefox. No development tools are required.

1. Extract the complete ZIP. Keep Stencil Studio.app intact. You can keep it in
   a normal user folder or move it to your own Applications folder.
2. Open Stencil Studio.app. Your default browser opens the local Studio.
3. Choose artwork, then Make Stencil. Customize, preview and export the result.
   Save Project keeps a portable copy of the project and its original artwork.
4. Reopen the launcher later and use Open Project to continue a saved file.
5. Finish and download batch results before quitting. Closing all Studio tabs
   stops the launcher after a short delay. Quit Studio in the small launcher
   window stops it immediately. Jobs do not continue after Studio closes.

The package filename identifies Apple Silicon, Intel or Universal. A Universal
package contains both architectures. Consult the platform test record for the
exact macOS/browser versions actually qualified. The native launcher's build
target is macOS 13.3 or newer; this does not certify every older OS/browser pair.

The bundle is ad-hoc signed for integrity, not signed with a paid Apple Developer
ID and not notarized. macOS can block a newly downloaded app. After verifying
your trusted seller and published SHA-256, use Apple's app-specific procedure:
try opening the app, then System Settings > Privacy & Security > Open Anyway
for this application if macOS offers it. Follow the system's confirmation.
Do not disable Gatekeeper globally. See Apple's current instructions:
https://support.apple.com/en-us/102445

A supported browser must already be installed. Initial download/browser setup
needs internet; normal processing, projects and exports work locally afterward.
Artwork is not uploaded. The package does not install a WebView runtime or ask
for accounts, subscriptions or recurring licensing checks.

Keep your own saved project files. Browser drafts belong to that browser and
local Studio address. Private browsing, unavailable storage and full storage
cannot provide a durable draft; use Save Project before closing.

If Studio does not open: check the package architecture, OS requirements, complete
extraction and macOS's application-specific warning. Do not mix files from two
packages. A busy old draft address can use a temporary session; reopen a saved
project there, or close the other application and relaunch for the old draft.

To update: save your project, quit Studio and replace the application with the
new complete bundle. Settings remain in your user Library application-data
folder; exports and saved project files are not removed by replacing the app.
To remove: quit Studio and move its app bundle to Trash. Browser drafts remain
separate; use the browser's site-data controls if you also want to erase them.

Physical print strength and printer-specific fit remain printing/calibration
tasks. Bundled fonts and other third-party components retain their own licenses.
