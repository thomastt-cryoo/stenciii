STENCIL STUDIO - OFFLINE BROWSER EDITION FOR WINDOWS

This package opens the complete editor in your normal web browser. It is not a
native desktop editor. You do not need Rust, Node.js, Python or WebView2.

1. Extract the complete ZIP into a folder you can write to. Do not open the
   program while it is still inside the ZIP. Keep Studio Support beside it.
2. Double-click Stencil Studio.exe. Your default browser opens Studio locally.
3. Choose an image, then Make Stencil. Customize and preview before exporting.
   Save Project creates a portable file containing your artwork and settings.
4. To continue later, open the launcher and use Open Project for a saved file.
5. Finish and download batch results before closing. Jobs require Studio to
   remain open; closing all Studio tabs stops the local launcher after a short
   delay. Quit Studio in the small launcher window stops it immediately.

Chrome and Edge are the recommended browsers. Consult Platform Test Record.txt
for exact versions tested and Firefox graphics qualification limits.
A browser must already be installed; this ZIP contains no browser installer.
Initial download and browser installation need internet. Processing, projects
and exports work locally without internet afterward. Artwork is not uploaded.
If your default browser is not qualified, open Chrome or Edge and copy the local
address shown in the small launcher window into its address bar.

Keep downloaded project files as your own backups. The browser's draft belongs
to that browser and local Studio address. Private browsing and unavailable or
full browser storage do not provide a durable draft. Use Save Project.
To move work from an older Studio version or local address, use Save Project
there first, then Open Project in this edition. Drafts do not move automatically.

The launcher is unsigned. Windows may display an unknown-publisher or reputation
warning for an internet download. Do not disable antivirus or Windows security.
Use only your trusted seller's package and published SHA-256. If Windows blocks
it, consult the included technical test/requirements record or contact support.

If Studio does not open: check that the entire ZIP was extracted, that Studio
Support is present, that the package is not corrupt, and that a supported browser
is installed. Close any previous Studio launcher and try again. If a saved draft
address is busy, the launcher offers a temporary session; open a saved project
there, or close the other application and relaunch to return to your old draft.

To update: save your project, quit Studio, and extract the new package into a new
folder. Do not mix launchers and support files from different packages. Startup
settings remain in %LOCALAPPDATA%\Stencil Studio\Stencil Studio\data.
Keep saved project files outside the application folder.

To remove: quit Studio and delete its extracted folder. Your exported models and
saved project files remain yours. Browser drafts are separate; use that browser's
site-data controls if you also want to erase them. No administrator installation
or recurring subscription/licensing check is required.

This is file-generation software. Physical print strength and printer-specific
fit require your own printing and calibration checks. Included licenses apply
to the bundled third-party components and fonts.
